# Contact icons

Signal and WhatsApp source artwork: Simple Icons (CC0).

- https://github.com/simple-icons/simple-icons/blob/develop/icons/signal.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/whatsapp.svg

The email envelope is a project-authored vector. Transparent 96 × 96 WebP renders (Signal blue #5A91FF (lightened for the dark contact background), WhatsApp green #25D366, and the email envelope in the site’s peach accent) are served from `static/images/icons/`; these source SVGs are not served.
